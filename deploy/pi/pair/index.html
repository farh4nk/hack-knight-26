Pair this device

Install the local certificate so your browser trusts Cribby on this network.

⬇ Step 1 — Download the certificate

Download certificate (ca.crt)

The file ca.crt will download. Keep it — you'll install it in the next step.

📱 Step 2 — Install & trust (pick your device)

1. Open Settings → tap Profile Downloaded (or General → VPN & Device Management) → tap the Cribby profile → Install.
2. Go to Settings → General → About → Certificate Trust Settings.
3. Under "Enable Full Trust for Root Certificates", find the Cribby CA and toggle it ON. Confirm the warning.
1. Open Settings → Security & privacy → More security settings → Install certificates → CA certificate (path may vary by Android version).
2. When prompted, allow the Settings app to install certificates if needed.
3. Select the downloaded ca.crt file. Name it "Cribby" and confirm.
4. Some Android versions require a lock screen (PIN/pattern) to install a CA cert.
1. Open Keychain Access (Cmd+Space, type "Keychain").
2. Drag ca.crt into the System keychain (or login keychain). Enter your admin password.
3. Double-click the imported "Cribby" certificate → expand Trust → set "When using this certificate" to Always Trust.
1. Press Win+R, type certmgr.msc, press Enter.
2. Right-click Trusted Root Certification Authorities → Certificates → All Tasks → Import.
3. Select ca.crt, choose "Place all certificates in the following store" → Trusted Root Certification Authorities → Finish.
4. Confirm the security warning. The certificate now appears under Trusted Root CAs.
Chrome / Edge / Brave: Settings → Privacy and security → Security → Manage certificates → Authorities → Import → select ca.crt → check "Trust this certificate for identifying websites".
Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import → select ca.crt → check "Trust this CA to identify websites".
System-wide (Debian/Ubuntu): sudo cp ca.crt /usr/local/share/ca-certificates/cradleecho.crt && sudo update-ca-certificates
Why this is safe: The certificate never leaves your local network. It only lets this device trust the Cribby monitor running on your Pi — nothing else.
